# Parallel Latent Reasoner (PRLR) — Experimental Research Preview

Interactive Web Demonstration for **Parallel Latent Reasoner (PRLR)**: Continuous Latent Deliberation with Recurrent Depth on Apple Silicon.

> ⚠️ **Research Preview Notice**: This demonstration is an experimental research prototype undergoing active development. Legacy compact model checkpoints have been archived due to the retired pooled-vector decoder.

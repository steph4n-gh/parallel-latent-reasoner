# Archived Synthetic Scaffold Reports

> ⚠️ **HISTORICAL ARTIFACT ONLY — DO NOT USE AS EMPIRICAL EVIDENCE**

The files in this directory (`BENCHMARK_REPORT_LARGE_GEMMA4.md`, `cognitive_benchmark_summary.json`, and `BENCHMARK_REPORT.md`) represent an early development scaffolding stage where:

1. **Ground-Truth Substitution**: The evaluation harness substituted stored `case.ground_truth` strings into the evaluation output when `adapter_loaded` was True, rather than scoring raw model-generated bytes.
2. **Hardcoded CoT Traces**: Autoregressive reasoning traces were simulated with fixed templates rather than run on a real pretrained base model.
3. **Microbenchmark Latency Comparison**: Timing measured 8 parallel recurrent sweeps against 200 serial recurrent iterations on a compact 256-dim MLX model, which constitutes a recurrent-kernel throughput test rather than an equivalent-quality reasoning comparison against a pretrained language model.

These files are preserved solely for auditability and development history. Genuine, uncompromised model evaluation is documented in the root benchmark runners.

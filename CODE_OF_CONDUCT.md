# Code of Conduct

Following the philosophy of Omarchy Linux, this project does not maintain a formal bureaucratic code of conduct.

Instead, we operate under straightforward human principles:

1. **Focus on Technical Excellence**: We are here to build great, high-performance software. Feedback and discussions should center on code quality, architectural elegance, and technical merit.
2. **Basic Respect & Courtesy**: Treat fellow contributors with respect. Assume good faith, listen to differing viewpoints, and communicate directly without personal attacks.
3. **Act Like Adults**: Be constructive, accept responsibility for mistakes, and resolve technical disagreements through empirical evidence and benchmarks.
4. **Maintainer Discretion**: Maintainers reserve the right to moderate or remove disruptive, bad-faith, or spam behavior to protect the productivity and focus of the project.
